## Known limitations / required acceptance
1. The ZIP uses ZIP32 stored entries, without compression; exports over 4 GiB fail. If the archive becomes too large, implement ZIP64/multipart export before relying on browser backup.
2. The complete backup contains password hashes, personal user information and all events. Store it encrypted and never publish or commit it to GitHub. ZIP download is not a one-click restore.
3. Restoring: **stop the server**, back up the destination runtime, extract the ZIP into the `EVENTFLOW_DATA` directory (`data.json`, `media/`, `backups/`), and restart. Test restoration in an isolated instance first.
4. External links and local linked-host paths cannot be embedded automatically in the DJ package; the manifest records references. Cross-host media must be uploaded first.
5. Browser autoplay restrictions and true cross-device audio output are not solved by server status alone. Only the DJ operator's browser plays audio; LED viewers receive event state, not live streaming audio.
6. Awards reorder from the dedicated live queue is not yet drag-and-drop. Use the Award Planner controls until the live award DnD UI passes acceptance.
7. Existing app uses a single Node.js JSON writer and in-memory sessions/leases. Do **not** run multiple independent replicas against the same runtime and do not expose the current beta publicly.
8. Coolify release requires HTTPS, secure production cookies, durable volumes, application health check, firewall configuration, restore rehearsal and event-day operational runbook.
9. PWA home-screen manifest exists; service worker/offline behavior has not been approved or verified. Never cache private media or authenticated APIs offline by default.
10. Human browser QA across Chrome/Edge, mobile and a second device remains required.

## Recovery
Before any production update, copy the entire data directory externally and test extraction. Keep the previous known-good Git commit/branch; use a staging deployment with a distinct runtime. Never let staging and production share `EVENTFLOW_DATA`.
