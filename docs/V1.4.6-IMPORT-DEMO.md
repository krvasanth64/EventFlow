# EventFlow V1.4.6 beta — Excel Import and Demo Studio

## Import from Excel workbook
**Excel Import & Demo** is accessible to Admin and Editor. Download the workbook template, fill the four sheets, upload the .xlsx (maximum 8 MB), preview errors, then create a new event. Existing events are not overwritten.

| Sheet | Purpose |
|---|---|
| Event | Title, date (YYYY-MM-DD), start (HH:MM), venue, organizer, description |
| Programs | Program Ref, title, type, category, minutes, gap minutes, presenter, source type, URL/linked reference, notes |
| Participants | Program Ref, employee code, name, contact; Program Ref joins a participant to its program |
| Awards | Category, Award Title, Winner, Presented By, Employee Code, Contact, Notes |

The imported **Program Ref** (such as REF-01) is only used to join rows in Excel. Permanent event codes P0001, P0002, A0001, A0002 are created independently and never track drag-and-drop order. File media is NOT imported from a local path; select Source Type = file and upload the actual file from Program Planner after import. URL source links beginning with http(s) are preserved; external sites may restrict embedded playback.

Preview reports errors and counts; import rejects invalid/duplicate program references, duplicate participant employee codes within a program, malformed source URLs, unsupported formula cells, excessive rows, and a duplicate event title. Import saves only after complete validation. Limits: 200 programs, 1,000 participants, 200 awards, 250 participants/program.

## Admin-controlled demo events
- The Admin toggles **Demo events visibility** in Import & Demo.
- When disabled, existing demo records remain on disk; non-Admin users do not see them in event lists or direct event views. No records are deleted.
- Admin can create a full sample event only while demos are enabled.
- The demo event contains 8 programs with participant rosters, 4 awards, an illustrative URL, and **two generated 4-second WAV sample media files**. Sample tones are for testing, not copyrighted music.
- Sample event data is separate from real event data; real events are never overwritten.
- Disabling demo events is a visibility switch, not data deletion or a security classification.

## Redesigned Backstage Preparation
- Top summary: active on-air program, upcoming programs, expected participants, checked-in participants, readiness percentage, and progress indicator.
- First upcoming program receives a prominent Next on Stage visual highlight.
- Four responsive cards with P-code, title, roster list, individual check marks and progress.
- Admin, Editor and Live Controller can mark ready; Viewer is read-only.
- Next-four list follows current running order automatically. The active program is unaffected by check-in.
