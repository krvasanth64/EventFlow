## PDF Report Designer
- Reports offers **Configure & Download Program PDF** and **Configure & Download Award PDF**.
- Awards also provides **Configure Award PDF**.
- The user may show/hide columns, reorder them with up/down buttons, adjust each relative width (4–80), set portrait/landscape A4 and font size (6–11 pt).
- **View PDF** opens the actual generated PDF in a new tab; **Download PDF** saves the binary file. A popup blocker may prevent View PDF; download remains available.
- Program ID `P####` and Award ID `A####` are selectable columns and enabled by default. They remain fixed regardless of live order.
- Table headers repeat on each page. Report data is read-only and Viewers may download PDFs.
- Layout preferences are saved locally in the browser per report type, not in the event database.

## Append Excel into an existing event
- Program Planner: **Import Programs XLSX**. Template contains Programs and Participants linked by temporary Program Ref.
- Award Planner: **Import Awards XLSX**. Template contains only Awards.
- Both require an Admin or Editor with an active event editing lease.
- Upload workbook, click **Preview & Validate**, then explicitly **Append to this Event**. Existing rows are not changed.
- Program titles already present are rejected. Award/winner duplicate pairs are rejected.
- Permanent P####/A#### numbers are allocated by the server during append; Excel cannot override them.
- Program file media is not read from the Excel file. Upload source media after appending. URL and linked references are carried across.
- Concurrent changes are rejected with event revision 409. Re-preview to refresh.
