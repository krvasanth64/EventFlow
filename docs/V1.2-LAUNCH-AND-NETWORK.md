## Windows host — install and verify

1. Stop EventFlow with Ctrl+C.
2. Make a copy of `D:\EventFlow\runtime` (including the JSON database, uploaded media and backups). Do not upload runtime to GitHub.
3. Update:

   ```powershell
   cd D:\EventFlow
   git pull --ff-only origin main
   node --check server.js
   node --check public/app.js
   node --check public/extensions.js
   node --check public/v12.js
   npm test
   ```

4. On the host, open **PowerShell as Administrator** and enable trusted LAN inbound access:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File "D:\EventFlow\scripts\allow-lan-firewall.ps1"
   ```

   This script creates a firewall rule for TCP 8765 on **Private** Windows network profiles for **LocalSubnet** clients only. It does not open public internet access. Check the active adapter with `Get-NetConnectionProfile`; keep public/untrusted connections on the Public profile.

5. Restart `start-eventflow.bat`. Expected console line includes `EventFlow at http://0.0.0.0:8765`.
6. Verify host:

   ```powershell
   Invoke-RestMethod http://127.0.0.1:8765/api/health
   Get-NetTCPConnection -State Listen -LocalPort 8765
   ipconfig
   ```

   Expected: `version: 1.2.0` and listener `0.0.0.0:8765` (or an equivalent IPv6 wildcard). Note the host's actual IPv4 LAN address.

7. On another PC **on the same LAN**:

   ```powershell
   Test-NetConnection HOST-LAN-IP -Port 8765
   ```

   Replace `HOST-LAN-IP` with the actual address. Visit `http://HOST-LAN-IP:8765`. If it fails, check firewall profile, VLAN routing, guest Wi-Fi isolation, subnet and any additional endpoint-security firewall.

## Tailscale access

The host may listen on 0.0.0.0 while Tailscale Serve still forwards to loopback:

```powershell
tailscale serve --bg --https=443 http://127.0.0.1:8765
tailscale serve status
tailscale status
```

Use the HTTPS address printed by Tailscale. **Serve is tailnet-only:** a phone or remote PC must be authorized into the same tailnet. An ordinary browser on the open internet cannot reach it unless Funnel is configured separately; Funnel is not enabled by these instructions. Keep Funnel disabled for the app's lightweight authentication.

If Serve status is correct but a device cannot connect, confirm the device's Tailscale connection, tailnet membership, DNS/route availability, and the host app's `/api/health` response.

## Usage guidance

Media plays locally in the operator's browser; EventFlow does not broadcast audio/video output to other attendees. Do not allow multiple operator browsers to play a video's audio through the same sound system. Viewers may open the script and preview source. Changes are controlled by the **single editor per event** lock.

When an event runs late, the actual start/end and elapsed time feed revised future start and end estimates. Original planned times are retained. The live editor may change durations or reorder upcoming programs. Completed, skipped and active slots are protected against moving while live to avoid falsifying historical order.

If a source is a web URL, the application opens that source in a separate tab; it does not attempt to bypass third-party autoplay or embedding restrictions.
